GCC runtime libraries — GPL-3.0-or-later WITH GCC-exception-3.1

Texts: COPYING3 and COPYING.RUNTIME, from the GCC source tree.
Upstream: https://gcc.gnu.org/

Bundled libraries:
  * libgomp (GNU OpenMP): torch's CPU thread pool.
  * libstdc++ and libgcc_s: copied from the build host, for the C++ libraries.
  * libgfortran: from the numpy and scipy wheels, for OpenBLAS.

The GCC Runtime Library Exception lets these libraries travel with a proprietary
or differently licensed program without the program becoming GPL. No source
offer is needed for the runtime libraries themselves.
